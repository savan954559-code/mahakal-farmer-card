महाकाल डिजिटल सेंटर — मराठी शेतकरी कार्ड जनरेटर

index.html फाईलमध्ये वेबसाइट आहे. इंटरनेटसह ब्राउझरमध्ये उघडा. PDF डाउनलोडसाठी CDN लायब्ररी लोड होणे आवश्यक आहे.

मोफत ऑनलाइन प्रकाशित करण्यासाठी GitHub वर सार्वजनिक repository तयार करा, index.html अपलोड करा, Settings > Pages > Deploy from branch > main /(root) निवडा आणि Save करा. Pages URL उपलब्ध झाल्यावर तो शेअर करा.

माहिती ब्राउझरमध्येच प्रक्रिया होते; या डेमोमध्ये सर्व्हरवर साठवली जात नाही. संवेदनशील माहिती भरण्याबाबत काळजी घ्या. कार्ड वैयक्तिक वापरासाठी आहे; सरकारी ओळखपत्र नाही.
